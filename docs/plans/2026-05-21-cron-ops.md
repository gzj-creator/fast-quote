# Cron Operations Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add scripts to start fastquote at 09:30, stop it at 15:00, and write runtime logs to disk.

**Architecture:** Keep scheduling outside the Rust process. Shell scripts own process lifecycle, pid files, and log redirection; cron owns clock-based start and stop.

**Tech Stack:** Bash, cron, existing `target/release/fastquote` binary.

---

### Task 1: Add runtime lifecycle scripts

**Files:**
- Create: `scripts/start_fastquote.sh`
- Create: `scripts/stop_fastquote.sh`

**Steps:**
1. Add a start script that resolves the repo root, creates `logs/`, `run/`, and `data/`, prevents duplicate starts via `run/fastquote.pid`, builds the release binary if it is missing, and appends app logs to `logs/fastquote-YYYY-MM-DD.log`.
2. Add a stop script that reads `run/fastquote.pid`, sends SIGTERM, waits up to a configurable timeout, removes stale pid files, and appends control messages to the same dated log.
3. Run `bash -n scripts/start_fastquote.sh scripts/stop_fastquote.sh`.

### Task 2: Add cron installer

**Files:**
- Create: `scripts/install_fastquote_cron.sh`

**Steps:**
1. Add an idempotent installer that removes the previous managed crontab block and installs weekday 09:30 start and 15:00 stop entries.
2. Redirect cron command output to `logs/fastquote-cron.log`.
3. Run `bash -n scripts/install_fastquote_cron.sh`.

### Task 3: Add operator docs and git ignores

**Files:**
- Modify: `.gitignore`
- Create: `docs/fastquote-operations.md`

**Steps:**
1. Ignore `logs/`, `run/`, and local SQLite database files under `data/`.
2. Document manual start/stop, cron install, log files, pid file, and the weekday-only schedule.
3. Verify generated docs and scripts are present in `git diff --stat`.
